Course Description(unordered list)

C Programming
In this course, students will learn the fundamentals of programming using the C language. Topics covered include data types, control structures, functions, arrays, and pointers. Students will gain hands-on experience through coding exercises and projects.
Java
In this course, students will learn the fundamentals of programming using the Java language. Topics covered include object-oriented programming, data structures, and algorithms. Students will gain hands-on experience through coding exercises and projects.
